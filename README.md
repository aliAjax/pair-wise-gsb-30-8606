# 油品配送装车 · 可恢复流程

- 行业：石油（油库装车发运）
- 技术栈：Vue3、Vite、TypeScript、Pinia
- 启动：`npm install && npm run dev`
- 构建：`npm run build`
- 流程断言：`npm run verify`（36 项端到端断言）

数据保存在浏览器 localStorage（键 `hxwlfront-19-oil-loading-workflow`），可用“重置演示数据”恢复种子。

## 业务流程

配送单 → 油罐车罐容占用 → 地磅回执核销 → 放行发车，全链路可恢复、可审计。

1. **确认前按油品预占罐容**：确认时校验司机证件有效期、油品兼容（单车次不可混装）、剩余罐容；
   写入 `HELD` 占用台账，车辆同时只服务一张未发车单。
2. **两窗口互斥**：全局“窗口确认权”只允许一个窗口的确认进入流程；同车并发的第二单被拦截，只放行一单。
3. **可恢复 Saga**：确认分 `CLAIM_WINDOW → VALIDATE → PERSIST_LEDGER → BIND_ORDER → DONE` 五步检查点，
   台账写入可注入故障；恢复时已完成步骤幂等跳过、台账存在性校验，不重复占车。
4. **地磅回执核销**：皮重+毛重回执到齐后算净重；吨数差异在 ±0.3t 容差内自动核销并释放占用，
   超差挂“差异待复核”，**未复核不能发车**；同类型回执可被地磅改写并留痕。
5. **司机证件过期巡检**：
   - 未发车单：占用置为 `INVALIDATED`、释放罐容，单据转“占用失效”并给出**重算范围**（受影响单据、释放吨数、改派建议）；
   - 已发车单：保留原始确认与回执依据快照，不受影响。
6. **列表与审计**：列表展示每张单的占用（HELD/已释放/失效）、差异与重算范围；
   审计表记录每次确认、拦截、中断/恢复、回执改写、核销、复核、发车、巡检的明细与影响范围。
